# Letter Count

Counts how many times a given letter appears in a word (case-insensitive).

![demo](demo.gif)

## Run it
```bash
gcc letter_count.c -o letter_count
./letter_count
```

## Example
```
Enter a word: banana
Enter a letter: a
'a' appears 3 time(s) in "banana"
```

## Concepts
Strings as char arrays, loops, `scanf`, `tolower`.
